# rag-chunking-retrieval-evaluation
An experimental study of how chunk size, overlap, and Top-K retrieval affect answer quality and reliability in Retrieval-Augmented Generation (RAG).

# Evaluating Chunking and Retrieval Parameters for Answer Reliability in RAG

## Overview

This project investigates how chunk size, chunk overlap, and Top-K retrieval settings affect retrieval quality, answer quality, and context size in a Retrieval-Augmented Generation (RAG) system for AI/ML research papers.

The project uses a collection of 10 arXiv research papers and evaluates different retrieval configurations experimentally.

## Objectives

- Study the effect of chunk size, overlap, and Top-K on retrieval performance.
- Compare answers generated with retrieved context against a no-RAG baseline.
- Evaluate retrieval recall, answer quality, hallucination flags, and retrieved context size.
- Analyze trade-offs between answer quality, retrieval coverage, and context length.

## Project Workflow

1. **Dataset Preparation:** Collect, extract, clean, and structure AI/ML research papers from arXiv.
2. **Chunking and Retrieval:** Generate parent chunks and smaller embedding windows, create embeddings, and retrieve relevant passages using FAISS.
3. **Answer Generation:** Generate answers using a language model with retrieved context and compare them with a no-RAG baseline.
4. **Evaluation:** Analyze recall, answer quality, hallucination flags, and context size.

## Experimental Setup

 Parameters

 Research papers - 10 
 Evaluation questions - 30 
 Chunk sizes - 250, 500, 750, 1000, 1500 tokens 
 Chunk overlaps - 0, 50, 100, 200 tokens 
 Top-K - 1, 3, 5, 10 
 Total configurations - 80

## Evaluation Metrics

- **Paper-level Recall@K:** Measures how many expected supporting papers appear in the retrieved results.
- **Answer Quality:** Scores answers on a 0–2 scale.
- **Hallucination Flags:** Records whether the automated judge identifies unsupported or contradictory claims.
- **Context Size:** Measures the amount of retrieved text supplied to the generator.

## Key Findings

The initial evaluation showed higher average answer-quality scores for RAG than for the no-RAG baseline. Increasing Top-K also increased average retrieval recall and context size. Medium chunk sizes showed higher average answer-quality scores than the largest tested chunk size.

These findings are exploratory and should be interpreted with the limitations of automated evaluation and the small evaluation set in mind.


## Limitations

- The corpus contains only 10 research papers and the evaluation uses 30 questions.
- Answer quality and hallucination flags are generated by an automated judge and have not been independently human-verified.
- Recall is measured at the paper level rather than the passage level.
- The no-RAG baseline contains 30 unique answers, whereas the RAG evaluation spans multiple configurations.
- Small differences between configurations have not been tested for statistical significance.
